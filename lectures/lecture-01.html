1. Что такое программирование

Практически любой современной техникой управляет программа.

Телефон. / Автомобиль. / Самолет. / Банковская система. / Робот. / Даже стиральная машина.

Программа — это последовательность инструкций, записанных на языке программирования и предназначенных для выполнения компьютером.

Компьютер не понимает человеческий язык.

Он понимает только машинные инструкции.

Процесс

Исходный код

Это обычный текстовый файл.

Например: main.cpp

Компилятор

Переводит программу из языка программирования в машинный код.

Компилятор не запускает программу. Он только переводит её.

Компоновщик (Linker)

Если программа состоит из нескольких файлов

main.cpp
math.cpp
io.cpp

каждый компилируется отдельно.

Потом linker объединяет их.

Исполняемый файл

Windows : program.exe

Linux : program

Процесс

Когда запускаем программу операционная система создает процесс. Именно процесс занимает память и использует процессор.

Небольшая демонстрация

g++ main.cpp -o app

./app

4. Современный C++

Краткая история.

  • 1985 - Первая версия языка.
  • 1998 - Первый международный стандарт.
  • 2011 - Практически новый язык.
  • 2014 - Минорные улучшения и исправление дефектов C++11 (C++14).
  • 2017 - Очень популярный стандарт.
  • 2020 - Еще больше современных возможностей.
  • 2023 - Последний стандарт.

Мы изучаем современный C++.

Не C++98.

Не Turbo C++.

Не Borland C++.

Что это означает?

На протяжении курса будем использовать современные рекомендации.

Например:

не так int x = 5; , а так int x{5};

Не NULL , а nullptr

Не (double)x , а static_cast<double>(x)

Не typedef, а using

Сейчас эти конструкции могут быть непонятны, но к ним будем возвращаться позже.

5. Парадигмы программирования

Что такое парадигма?
Это подход к написанию программ.

  • Процедурная (Именно её будем изучать)

    • Программа состоит из функций.

  • Объектно-ориентированная (Следующий семестр)

    • Программа состоит из объектов.

  • Функциональная (Используется в современных языках)

    • Вычисления строятся как композиция функций.

  • Обобщенное программирование

    • Один алгоритм работает с разными типами.
    • Позже познакомимся с шаблонами.

VS Code

Это не компилятор. Это редактор кода с расширениями. Внутри работают

  • g++
  • Git
  • GDB
  • терминал

WSL (Windows Subsystem for Linux)

Linux внутри Windows. Почему?
Большинство серверов работает под Linux. Большинство инструментов разрабатывается под Linux.

g++

Компилятор.

Git

Система контроля версий. Позволяет возвращаться к предыдущим версиям программы. Даёт возможность работать в команде.

GDB

Отладчик. Позволяет остановить программу посмотреть значения переменных выполнять программу по шагам.

9. Первая программа

#include <iostream>

int main() {
    std::cout << "Hello, World!\n";
    return 0;
}
  • #include — подключение библиотеки (детально позже).
  • main() — точка входа программы.
  • std::cout — вывод текста (подробно на лекции о потоках).
  • return 0; — успешное завершение программы.
