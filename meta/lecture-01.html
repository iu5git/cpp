1. Что такое программирование

Практически любой современной техникой управляет программа.

Телефон. / Автомобиль. / Самолет. / Банковская система. / Робот. / Даже стиральная машина.

Программа — это набор инструкций и данных, записанных в форме, пригодной для обработки компьютером и выполнения определённой задачи.

Компьютер не понимает человеческий язык.

Процессор непосредственно выполняет машинные инструкции. Языки программирования высокого уровня требуют преобразования программы в форму, которую может выполнить вычислительная система.

Ассемблер

Большинство инструкций ассемблера напрямую соответствует машинным инструкциям процессора.

Например, в архитектуре x86:

MOV AX,10   ; B8 0A 00 или 10111000 00001010 00000000

ADD AX,5

Очень быстро.
Очень сложно.

Почему не Python?

Почему не Java? и не JavaScript?

Плюсы C++

  • Высокая производительность — программы работают очень быстро.
  • Низкоуровневый контроль над памятью и ресурсами — C++ позволяет работать с адресами, указателями, временем жизни объектов и системными ресурсами.
  • Компилируемый язык — Обычно компилируется в машинный код, что позволяет создавать высокопроизводительные нативные программы без обязательного использования виртуальной машины.
  • Поддержка ООП — классы, наследование, полиморфизм.
  • Многопарадигменность — процедурное, объектно-ориентированное и обобщенное программирование.
  • Большая стандартная библиотека (STL) — готовые контейнеры и алгоритмы.
  • Кроссплатформенность — Windows, Linux, macOS, встроенные системы.
  • Широкое применение — игры, ОС, драйверы, серверы, высоконагруженные приложения.

Минусы C++

  • Сложный синтаксис — высокий порог входа.
  • Нет встроенного сборщика мусора — управление ресурсами обычно строится на принципе RAII. При неправильном использовании динамической памяти возможны утечки и другие ошибки.
  • Долгая компиляция — особенно крупных проектов.
  • Нет встроенного сборщика мусора — память освобождает программист.
  • Сложная отладка — ошибки с указателями и памятью трудно искать.
  • Много возможностей допустить неопределенное поведение (Undefined Behavior) — выход за границы массива, использование не инициализированных данных и др.
  • Большой стандарт языка — много правил и особенностей, которые нужно знать.

Где используется C++

  • разработки операционных систем и драйверов;
  • создания компьютерных игр и игровых движков;
  • разработки браузеров;
  • создания профессиональных приложений (Photoshop, AutoCAD);
  • банковских и биржевых систем;
  • встроенных систем и микроконтроллеров;
  • серверного программного обеспечения;
  • библиотек искусственного интеллекта и машинного обучения.

    ↓

    ↓
Загрузка операционной системой
    ↓
Создание процесса
    ↓
Выполнение программы

Компилировать

g++ main.cpp -o app

запустить

./app

Для демонстрации отдельные этапы можно запускать отдельно:

Этап Команда Результат
Препроцессинг g++ -E main.cpp -o main.i main.i — код после обработки #include
Компиляция g++ -S main.i -o main.s main.s — машинно-ориентированный код
Ассемблирование g++ -c main.s -o main.o main.o — объектный файл
Компоновка g++ main.o -o main main (или main.exe в Windows) — исполняемый файл

Основные флаги

  • E— остановиться после препроцессора.
  • S— остановиться после компиляции (получить ассемблерный код).
  • c— остановиться после ассемблирования (получить объектный файл).
  • Без флагов — выполнить все этапы, включая компоновку.

Процесс

Процесс — это выполняющаяся программа вместе с выделенными ей ресурсами: адресным пространством памяти, состоянием выполнения, открытыми файлами и другими ресурсами операционной системы.

4. Современный C++

Под современным C++ обычно понимают стиль и возможности языка, сформировавшиеся начиная с C++11.

История языка С++

  • 1985 - Первая версия языка.
  • 1998 (C++98) — первый международный стандарт, STL.
  • 2003 (C++03) — исправления и улучшения.
  • 2011 (C++11) — auto, nullptr, лямбды, умные указатели, многопоточность.
  • 2014 - Минорные улучшения и исправление дефектов C++11 (C++14).
  • 2017 (C++17) — if constexpr, структурные привязки, optional, filesystem.
  • 2020 (C++20) — Concepts, Modules, Coroutines, Ranges.
  • 2023 (C++23) — расширение стандартной библиотеки и улучшение существующих возможностей.
  • 2026 (C++26) — следующий стандарт C++, находящийся на этапе формирования и стандартизации.

Мы изучаем современный C++.

Не C++98.

Не Turbo C++.

Не Borland C++.

5. Парадигмы программирования

Что такое парадигма?
Это подход к написанию программ.

  • Процедурная (Именно её будем изучать)

      В процедурном программировании программа строится как набор процедур и функций, которые последовательно выполняют действия и преобразуют данные.

Примеры языков: C, Pascal.

  • Объектно-ориентированная (Следующий семестр)

    • Программа состоит из объектов, которые содержат данные и методы.

    Основные принципы ООП:

    • инкапсуляция;
    • наследование;
    • полиморфизм;
    • абстракция.

Примеры языков: C++, Java, C#

  • Функциональная (Используется в современных языках)
    • Функциональное программирование рассматривает вычисления как применение и композицию функций и часто использует неизменяемые данные и функции как значения.

Примеры языков: Haskell, Lisp, F#.

  • Обобщенное программирование
    • Один алгоритм работает с разными типами.
    • Позже познакомимся с шаблонами.

Какие парадигмы поддерживает C++?

C++ — многопарадигменный язык. Он поддерживает:

  • процедурное программирование;
  • объектно-ориентированное программирование;
  • обобщенное программирование (шаблоны);
  • элементы функционального программирования (лямбда-функции).
  • C++ поддерживает несколько стилей программирования, включая императивный и метапрограммирование.

6. Инструменты разработчика

VS Code

Это не компилятор. VS Code — редактор кода и среда разработки, которая с помощью расширений может интегрироваться с внешними инструментами, например g++, Git, GDB и терминалом.

WSL (Windows Subsystem for Linux)

Linux внутри Windows. Почему?
Многие инструменты разработки и серверные технологии активно используются в Linux-средах. Значительная часть серверной инфраструктуры работает под управлением Linux.

g++

g++ — драйвер компилятора GNU, который управляет препроцессированием, компиляцией, ассемблированием и компоновкой программы.

Git

Система контроля версий. Позволяет возвращаться к предыдущим версиям программы. Даёт возможность работать в команде.

GDB

Отладчик. Позволяет останавливать программу, просматривать значения переменных и выполнять программу пошагово.

9. Первая программа

#include <iostream>

int main() {
    std::cout << "Hello, World!\n";
    return 0;
}
  • #include — подключение библиотеки (детально позже).
  • main() — точка входа программы.
  • std::cout — вывод текста (подробно на лекции о потоках).
  • return 0; — успешное завершение программы.
